  ```
  This network's firewall decrypts and re-signs HTTPS traffic before it reaches you.

   ! NODE_EXTRA_CA_CERTS="C:\path\to\fortinet-ca.crt" npm install @monaco-editor/react monaco-editor
   ```
   This keeps certificate checking on. It just adds one trusted issuer for that command.
